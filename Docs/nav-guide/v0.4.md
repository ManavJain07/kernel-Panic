## Features (v0.4)
- Shows current mode, active object and selection count
- Gives a plain-language hint and shortcut for the current situation
- **Guided goals (core feature):** say what you want to make ("a wall", "a window hole"). The add-on reads Blender's live state, starts at the first step you have not done yet, moves on by itself as you work, warns when you are in the wrong mode, and shows the current step as a banner inside the 3D view
- **Find a tool:** type what you want to do (e.g. "make a hole") and get the menu location, shortcut and a mode warning
- Guided tasks with a step-by-step checklist (viewport navigation, add/delete, transform, edit mode, extrude, materials, a simple wall)
- "Do it for me" buttons on steps, so beginners see what a step does

## Install
1. Install **Blender 4.2 LTS or newer**.
2. Download `navigation_guide.zip` from Releases (or build it, see below).
3. In Blender: `Edit > Preferences > Get Extensions`, open the dropdown at the
   top right, choose **Install from Disk**, and pick the zip.
4. In the 3D Viewport press `N` and open the **Nav Guide** tab.

## Build the zip
```
cd navigation_guide
zip -r ../navigation_guide.zip .
```
(The manifest must be at the root of the zip.)

## Project structure
```
navigation_guide/
  blender_manifest.toml   extension metadata
  __init__.py             register / unregister
  context.py              reads Blender state, produces hints
  navigator.py / recipes/ guided goals: recipes.json + the state-checking logic (navigation team)
  session.py              timer that watches Blender and advances steps
  overlay.py              banner drawn in the 3D viewport
  goal_ops.py             start / skip / stop a goal
  finder.py / tools/      Find-a-tool search and tools.json (navigation team)
  tasks.py / tasks/       task loader and tasks.json library (tutorial team)
  utils.py                shared UI helpers
  props.py                remembers chosen task and step
  operators.py            helper actions and step navigation
  panel_nav.py            navigation sidebar (navigation team)
  panel_tutorial.py       tutorial sidebar (tutorial team)
scripts/validate_*.py check the JSON data
```
