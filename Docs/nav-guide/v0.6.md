# v0.6.0: compact layout and livelier animations

## Layout (shorter, less cluttered)
- The whole sidebar is now **one panel with three pages**: Guide, Help, Tools. Only the active page is drawn, so the tab stays short.
- One status line replaces the "Where you are" box: `Object | Cube | 1 sel`, with two small icon toggles (overlay on/off, animations on/off)
- Picking a goal: search box and dropdown, each on a single row
- Following a goal: title row with a Stop button, a progress bar, and one box for the current step. The full step checklist is hidden behind an "All steps" toggle
- Help shows 3 tips per problem, with "+N more tips" to expand
- Tools shows the top 2 matches
- Text uses tighter line spacing

## Animations (livelier, more interactive)
- **Live progress bar** fills as you scale, move or rotate (size, height off the ground, degrees turned) and eases smoothly
- Banner **slides and fades in** on each new step
- Keycaps **press down** with a glow and stagger in; they bounce if you stay on a step for 15 seconds
- Mouse icon shows **click ripples**, and a moving dot with a trail for drags
- **Ripple rings** plus a bobbing arrow around the active object
- Axis line has **three travelling dashes**, and a bouncing X/Y/Z letter at its end
- **Step done!** burst when a step completes automatically, and **confetti** when a goal is finished
- After 15 seconds on one step: "Stuck? Open the Help tab"

## Changed files
navigation_guide/: overlay.py, panel_nav.py, session.py, navigator.py, goal_ops.py

## Not changed
