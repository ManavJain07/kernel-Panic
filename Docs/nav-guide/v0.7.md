# v0.7.0: finalised version

Baseline for these changes: v0.6.0. Applying the files in this change set to the v0.6.0 add-on gives exactly the finalised v0.7.0 add-on.

## What changed
- **Display toggles** are back to plain labelled checkboxes: "Show hints in the viewport" and "Animated guidance" (the icon toggles from v0.6 are gone)
- **Lag fixes**
  - Built-in shaders are created once and reused instead of every frame
  - The animation timer redraws only the 3D drawing region, not the whole area with the sidebar
  - Fast redrawing only runs while something on screen is actually moving
  - Confetti goes out as one batched draw call
- **Confetti fix**: the celebration now plays when a goal finishes, even though a finished goal has no current step
- **Command coverage**: Find a tool grows from 25 to 70 commands (search menu, repeat last, adjust last panel, box select, select modes, linked select, invert, fill, delete, dissolve, separate, subdivide, edge slide, bridge, proportional editing, normals, UV unwrap, shade smooth, apply transforms, set origin, parent, linked duplicate, hide/show, rename, collection, local view, orthographic, standard views, snapping, 3D cursor, pivot, numeric input, sidebar, wireframe, Mirror/Array/Solidify/Bevel modifiers, apply modifier, lights, camera, keyframes, play, open, save as)
- The Tools page shows a "Popular" list before you type, and up to 3 results per search
- **Guided goals**: 15 to 20 goals (76 steps). New: Model one side get both (Mirror), Build stairs, Make an object smooth, Light the scene and render a picture, Group objects so they move together
- **Troubleshooter**: 13 to 18 problems (63 causes). New: Moving or scaling goes the wrong way, It rotates or scales around a strange point, My modifier does nothing, Extrude loop cut or bevel does nothing, My render is black or empty
- Manifest version 0.7.0

## Files in this change set
navigation_guide/: blender_manifest.toml, finder.py, overlay.py, panel_nav.py, session.py, problems/problems.json, recipes/recipes.json, tools/tools.json

## Not changed
context.py, navigator.py, goal_ops.py, props.py, troubleshoot.py, operators.py, utils.py, `__init__.py`, all tutorial files, all scripts (the existing validators pass on the new data).
