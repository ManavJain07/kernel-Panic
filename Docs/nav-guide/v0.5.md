v0.5.0: animated guidance, more goals, troubleshooter

## What is new
- **Animated guidance in the 3D viewport**
  - Keycaps for the current step light up one after another (S, then X, then 4, then Enter), then loop
  - Animated mouse icon shows which button to use (left click, middle drag, scroll wheel)
  - Pulsing ring around the active object on select and transform steps
  - Pulsing X / Y / Z axis line with a moving dash on axis-constrained steps (S X 4, G Z 1.5)
  - Switch off with "Animated guidance" in the Nav Guide tab
- **15 guided goals (53 steps)**: move around the 3D view, wall, floor slab, column, ground plane, copy, repeat (Array), window/door hole, extrude a face, round edges, colour, turn 90 degrees, join, clear scene, save
- **"I'm stuck, what's wrong?" troubleshooter**: 13 common beginner problems with ordered causes
  - Checks the live scene automatically ("Right now I notice: you are in Wireframe shading")
  - Describe a problem in words, or pick from a dropdown
  - One-click fixes: Solid view, Object Mode, show hidden, select all, undo, recalculate normals
- Goal picker is now a dropdown (15 goals would not fit as buttons)
- New step conditions: mode_not, max_selected, min_objects, max_objects, fewer_objects, rot_min, active_hidden, saved
